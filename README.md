## helloShell.py

Shellcode to write 'Hello World' in the text file 'C:\hello.txt'

Template to start your Shellcoding tasks with time-saving functions that will make your shellcoding from several hours to a few moments with consistent practice.

Familiarize yourself with the time-saving functions below. Insert function outputs into Keystone variable CODE.

### ComputeHash32
Modified version of Module 7 ComputeHash.py. Modifications:
+ Takes Win32 API as String Name as input
+ Takes Buffer Offset Location (for later calls)
+ if second argument is "0x20" the API will be called as `EBP+0x20`
+ Computes Hashes as the Original
+ Hashes are checked for Bad Characters, identifies its position and pre-adjust assembly
+ 4 sets of assembly instructions depending on Bad Character Position

#### Usage and Keystone CODE insert
Example shows all functions used to write "Hello World" into "C:\\hello.txt"
Take note that the second argument will be called for later

```
CODE += ComputeHash32("CreateFileA",                                  "0x20")
CODE += ComputeHash32("WriteFile",                                    "0x24")
CODE += ComputeHash32("CloseHandle",                                  "0x28")
```

#### Win32 API Calls
```
"   call dword ptr [ebp+0x20]       ;"  #CreateFileA
"   call dword ptr [ebp+0x24]       ;"  #WriteFile
"   call dword ptr [ebp+0x28]       ;"  #CloseHandle
```

### LoadLibrary32
This function takes Library Name as string (example: 'ws2_32.dll' ) converts ascii to byte chunks.
+ Process String ASCII into Assembly as argument for LoadLibraryA
+ Stores Output Base Address into EBX

#### Sample Usage: WSASocketA from ws2_32.dll Library
[ ! ] EBX Register Shared
+ LoadLibrary32 will be immediately followed by the Win32 API helper function ComputeHash32 because the Base Address is in EBX which is shared by both functions and will be overwritten on a new LoadLibrary32 call

```
CODE += LoadLibrary32("ws2_32.dll")
CODE += ComputeHash32("WSASocketA",                                   "0x38")
```

WARNING: LoadLibrary32 function assumes LoadLibraryA call will be at `EBP+0x10`. 
```
        chunks.append(f"  call dword ptr [ebp+0x10] ;")

```
This is the first thing to check for mismatch between ComputeHash and LoadLibrary32 calls

#### Usage
Compute and Set LoadLibraryA at EBP+0x10
```
CODE += ComputeHash32("LoadLibraryA",                                 "0x10")
```


### IP and Port Converters
Pack IP Address String and Port Integer so that it can be pushed as socket arguments in assembly. It comes with Bad Character detection

#### Usage
```
LHOST = ipByte(LHOST)
LPORT = portByte(LPORT)
```

#### Keystone CODE insert
```
CODE += (f"   push {LHOST}          ;")#   Push sin_addr
CODE += (f"   mov   ax,{LPORT}      ;")#   Move the sin_port 
```

#### String Buffer Functions
Function packStrings take string from input, pack it into EDI buffer using STOSD and STOSB instructions. 
[!] Strings can be file paths. 
[!] Reserve buffer first. 
[!] Null Terminator included.


#### Usage and Keystone CODE insert
Shown below buffer reservation and packStrings usage for destination file "C:\hello.txt"

```
CODE +=("   lea edi, [ebp-0x204]            ;")
CODE += packStrings("C:\\hello.txt")
```
Also included packStringsAppend, which removed the null terminator, useful in path creation that has a dynamic length somewhere in the file/directory.

## ingestRop.py

A helper script for processing ROP gadget output generated from `rp-win-x86.exe`

The script reduces thousands of gadget results into categorized, usable ROP gadgets that:

+ Unique
+ Bad Character Filter
+ Categorized
+ Output to a File

### Usage

```bash
python3 ingestRop.py -f osed.txt -b "\x00\x0a\x0d"
```

### Arguments

- `-f`, `--file`: Input file containing output from `rp-win-x86.exe`
- `-b`, `--badchars`: Optional bad characters to exclude, such as `\x00\x0a\x0d`

If no bad characters are specified, the script continues without bad-character filtering.


### Requirements

- Python 3
- Text output generated by `rp-win-x86.exe`
